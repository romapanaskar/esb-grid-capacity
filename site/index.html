About the data

Sourced from ESB Networks' publicly available capacity heatmap export (July 2026), covering roughly 46,500 transformers and substations across Ireland. Each record reports installed capacity, current commitments, and — where a downstream bottleneck exists — the capacity that would be available if the parent constraint were resolved.

Data is processed offline (cleaning, feature parsing, model training) and served here as static files — this page does not run any live inference or fetch the ESB source directly.
